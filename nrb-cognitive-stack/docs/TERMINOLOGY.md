# Terminology — Glossary of All Terms

| Term | Definition |
|------|-----------|
| **COP** | Cognitive Operating Pipeline — the language understanding/generation engine |
| **GSRA** | Governance, Safety, and Regulatory Architecture — the safety governor |
| **PFT** | Perception Field Tracking — sensor signal processing |
| **GeneDB** | Gene Database — memory and priors storage |
| **CIL** | Cognitive Interpretation Layer — the runtime processing core of COP |
| **BCPL** | Bilingual Corpus Processing Layer — offline corpus processing |
| **LEAE** | Law Evaluation and Application Engine — GSRA law evaluation |
| **IPA** | Intervention Planning Architecture — GSRA intervention planner |
| **NRB-256** | Encoding format for gene objects (256-bit hash-addressed) |
| **Meaning Frame** | Structured semantic representation of understood input |
| **Trace Hash** | SHA-256 hash for audit trail verification |
| **Pseudo-Symbol** | PFT output converted to COP-compatible input format |
| **Law Vault** | Structured collection of safety/ethical/intervention laws |
| **Envelope** | Wrapper format for inter-system message passing |
| **Verdict** | GSRA decision output (ALLOW/BLOCK/MODIFY) |
| **Proto-Frame** | Preliminary frame from BCPL corpus processing |
| **Gene** | Atomic unit of memory in GeneDB |
| **Surface Generation** | Converting Meaning Frames to natural language (L3) |
| **MWE** | Multi-Word Expression — multi-token lexical unit |
| **Canonical JSON** | Deterministic JSON serialization (sorted keys) |
